# FlowHR Web (Angular)

## Setup

```bash
yarn install
yarn start
```

## API URL

`src/environments/environment.ts`

```ts
apiUrl: 'http://localhost:3000/api'
```

## Pages

- Login
- Dashboard
- Tenants
- Employees
- Leave
- Attendance
- Payroll
- Payslips
- Recruitment
- Reports

## Styling Direction

- White/light SaaS interface
- Indigo primary accents
- Rounded cards and spacious layout
- Responsive mobile sidebar
